# notes-and-code

Personal notes and code snippets, organized so they are easy to find and reuse.

## Contents

- [`notes/`](notes/) — explanations, reminders, and learning notes in Markdown.
- [`snippets/`](snippets/) — reusable code examples, grouped by language or topic.

## Adding material

- Give each note or snippet a descriptive filename.
- Include the language or tool in the filename when it helps, for example
  `python-read-json.py` or `git-commands.md`.
- Add a short explanation and any assumptions needed to use a snippet safely.
